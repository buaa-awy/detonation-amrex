# 可核对结果和验证状态

本页区分三类结果：

1. 安装/数值回归结果，可用于判断编译和基本执行是否正确；
2. 当前 70 μs 算例的实际诊断结果；
3. 尚未完成的物理验证。

## 化学自检

运行：

```bash
./build/chemtest
```

当前 9 组分/21 反应机理在已测试环境中应输出：

```text
implicit_ok=1
T=1803.729599 rho=0.1219636953
e0=2751170.248
```

允许末位差异，但 `implicit_ok` 必须为 1，温度、密度和能量不应出现量级变化。

## 100 步确定性回归

运行：

```bash
./scripts/run_smoke_test.sh
```

输入文件：

```text
examples/h2o2_2d_demo/inputs-smoke
```

参考结果：

| 项目 | 参考值 |
|---|---|
| 最终步数 | `100` |
| 最终物理时间 | `0.2256289898 μs` |
| 最大 AMR 层 | `3` |
| 总质量 | `1260.95732991` |
| 总能量 | `193540164.212` |

脚本采用相对容差：质量 `1e-10`、能量 `1e-9`，同时要求最终状态有限、
程序标记 `finished=true`。

## 长时间算例说明

`inputs` 和 `inputs-long` 是研究算例，不是已经通过网格无关性验证的标准答案。
完整 75 μs 算例在笔记本电脑上需要数小时，因此仓库不附带庞大的 checkpoint 和
场数据。用户应使用 `chk_time_int` 定期保存 checkpoint，并通过
`amr.restart=` 续算。

## 当前 70 μs 结果

已有的 `0.30 m x 0.02 m` 算例输出到 `70.001 μs`，运行状态记录到
`71.412 μs` 后停止。场图、中心线图和波前历史已经加入
[`VALIDATION_70US.md`](VALIDATION_70US.md)。

结论是：质量守恒为 `-3.0e-15`，能量守恒为 `-2.8e-14`，AMR 和输出流程正常；
但当前算例没有形成自持、紧密耦合的爆震。它不能作为“程序已正确复现爆轰”的
验证证据。
