# 可核对结果和验证状态

本页区分三类结果：

1. 安装/数值回归结果，可用于判断编译和基本执行是否正确；
2. 化学自检和短算例的可核对结果；
3. 物理验证的参考流程。

## 化学自检

运行：

```bash
./build/chemtest
```

当前 9 组分/21 反应机理在已测试环境中应输出：

```text
implicit_ok=1
T=1800 rho=0.1219636953
e0=2751170.248
```

当前单步化学自检还应输出有限且物理合理的 `omega_max` 和 `omj_max`。允许不同
GPU 构建的末位差异，但 `implicit_ok` 必须为 1，密度和能量不应出现量级变化。

## 100 步确定性回归

运行：

```bash
./scripts/run_smoke_test.sh
```

输入文件：

```text
examples/h2o2_2d_demo/inputs-smoke
```

参考结果：

| 项目 | 参考值 |
|---|---|
| 最终步数 | `100` |
| 最终物理时间 | `0.225628 μs` |
| 最大 AMR 层 | `3` |
| 总质量 | `1260.95732991` |
| 总能量 | `193540164.212` |

脚本采用相对容差：质量 `1e-10`、能量 `1e-9`，同时要求最终状态有限、
程序标记 `finished=true`。

checkpoint 续算从第 20 步的 `chk00020` 继续到第 40 步后，应复现与直接计算
相同的物理时间、时间步长、质量、能量和波前位置；AMR 单元组织可因重划网格
而不同。

## 长时间算例说明

`inputs` 和 `inputs-long` 是研究算例，不是已经通过网格无关性验证的标准答案。
完整 75 μs 算例在笔记本电脑上需要数小时，因此仓库不附带庞大的 checkpoint 和
场数据。用户应使用 `chk_time_int` 定期保存 checkpoint，并通过
`amr.restart=` 续算。

长时间算例的物理验证步骤、网格协调性要求和原 Python 对照方法见
[`VALIDATION_GUIDE.md`](VALIDATION_GUIDE.md)。
